# Ambience loop provenance

All four sources are **Creative Commons 0 (public domain)** recordings from
freesound.org — license verified on each sound page at download time. The
shipped files are derivatives: downmixed to mono, resampled to 8 kHz,
trimmed to a ~38.5s segment, end→start crossfaded (1.5s) for seamless
looping, and RMS-normalized so all templates sit at the same level.
