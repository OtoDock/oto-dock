Controls that save on change. A toggle, a select or a field that saves when it loses focus has no Save button, so it says what happened right after its label. Saving… shows once a save runs past 300 ms, so a fast one never flickers. Saved shows for two seconds, and a newer save takes its place. A failed save shows the reason beside the control and puts a toggle or a select back. A field keeps what was typed. This page fakes the saves, and every third one fails, so the failure shows too.

Customers get a message at the time below.
