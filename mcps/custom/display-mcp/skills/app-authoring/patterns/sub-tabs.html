A strip of tabs that scrolls sideways when it does not fit. The active tab is lifted on the card surface. Arrows appear only when the strip overflows and go quiet at each end. Use it for views inside one page. The days of a week, the columns of a report, the states of a list. Each tab names its own panel, so two strips on one page stay apart. For whole pages use the app shell instead.
